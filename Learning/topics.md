## Topics:
* How does a computer work?
* How does a program go from code to executable?
* How does an executable become a process?
* How does a process distribute work within itself?
* How does a system communicate with other systems?
* How do we measure a system?
* How do languages dictate systems?
---------
My goal is to try and tackle one of these per month, with either a presentation or (ideally) a visual representation in code to demonstrate and teach it
